# WEB-Profile-Aksi
**Personal Profile Website - Aksi Creator**

A modern, minimalist, and elegant personal profile website showcasing skills, portfolio, and contact information.

## ✨ Features

### 🎯 Hero Section
- Circular profile photo with hover effects
- Large name display with gradient text effect
- Professional tagline and description
- Call-to-action buttons with smooth animations

### 👤 About Me Section
- Clean description with organized content
- Feature cards with icons (Creative Design, Clean Code, Responsive Design)
- Modern card layout with hover effects
- Two-column responsive layout

### 💼 Portfolio Section
- Grid layout with project cards
- Project images, titles, and descriptions
- Technology tags for each project
- Hover animations and smooth transitions
- Sample projects: E-commerce Platform, Mobile App Design, Web Application, Brand Identity

### 🛠 Skills Section
- Animated progress bars for technical skills
- Two categories: Frontend Development & Backend & Tools
- Technology icons grid (HTML5, CSS3, JavaScript, React, Vue.js, Node.js, Git, Figma)
- Skills with percentage indicators

### 📬 Contact Section
- Contact form with floating labels
- Form validation and submission feedback
- Contact information with icons (Email, Phone, Location)
- Social media links (GitHub, LinkedIn, Instagram, Behance)
- Modern form styling with smooth animations

### 🎨 Design Features
- Modern minimalist design
- Gradient backgrounds and smooth animations
- Fully responsive design (mobile, tablet, desktop)
- Smooth scrolling navigation
- Fixed navigation bar with backdrop blur
- Interactive elements with hover effects
- Loading animations and transitions

## 🚀 Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Modern styling with Flexbox and Grid
- **JavaScript**: Interactive functionality and animations
- **Font Awesome**: Icons for UI elements
- **Google Fonts**: Inter font family for modern typography
- **CSS Grid & Flexbox**: Responsive layouts
- **CSS Gradients**: Modern visual effects
- **CSS Transitions & Animations**: Smooth user interactions

## 📱 Responsive Design

The website is fully responsive and optimized for:
- **Desktop**: 1200px+ (Full layout)
- **Tablet**: 768px - 1199px (Adapted layout)
- **Mobile**: Up to 767px (Stacked layout with mobile menu)

## 🎯 Key Design Principles

- **Minimalist**: Clean, uncluttered design focusing on content
- **Modern**: Contemporary design trends and techniques
- **Elegant**: Sophisticated color scheme and typography
- **User-Friendly**: Intuitive navigation and clear call-to-actions
- **Performance**: Optimized code for fast loading times

## 🌐 How to Run

1. Clone the repository
2. Open `index.html` in a web browser, or
3. Use a local server:
   ```bash
   python3 -m http.server 8000
   # Then open http://localhost:8000 in your browser
   ```
